## 下载与运行

- GitHub 的 Code → Download ZIP 可下载完整源码包。
- 通用求解器按根目录 README 安装依赖；运行根目录测试：`python -m pytest tests -q`。
- GPU/CPU 统一工作台：进入 `BGK_NEE_GPU_20260929`，在自己的 Python 虚拟环境中安装 `requirements-dashboard.txt`，运行 `python open_dashboard.py`。CUDA 后端还需要匹配的 NVIDIA 驱动及 CUDA 环境，具体见该目录 README_GPU.md。
- 部分原有 Windows 批处理保留了原机器的绝对 Python 路径；换机器时使用自己的 Python 运行对应 `.py` 入口，或自行调整批处理路径。源码包不包含虚拟环境。
- 各子工程的模块名存在重名。分别在各工程目录运行测试，不要从仓库根目录递归收集所有子工程的测试。
