# Lucide icons

The SVG files and LICENSE in this directory are unmodified assets from
https://github.com/lucide-icons/lucide at commit
`66d8f9fc394b8530377e5f6112f0b8908ba01280`.

Source paths: `icons/<name>.svg` and `LICENSE`.
Retrieved 2026-09-29. Rendered and tinted locally using QtSvg; no network
connection or icon service is required when the workbench runs.
