## 仿真控制

左侧“新建仿真”用于新任务，右侧用于观察选中的任务或历史结果。切换右侧记录不会悄悄覆盖左侧正在编辑的参数；已有记录可在数据档案中“复用参数”。

可选择三种后端：

| 后端 | 执行实现 |
|---|---|
| CPU · NumPy | BGK＋NEE 保留冻结算法；独立子类实现 MRT 与半格点反弹 |
| GPU · 融合 CUDA | 通过完整对照的双精度融合内核 |
| GPU · CuPy 对照 | 保留逐数组操作结构的双精度 GPU 参照 |

参数包含碰撞模型 BGK/MRT、壁面 NEE/HBB、N、Re、顶盖速度 U、残差阈值、最大和最少迭代步数、启动步数、报告间隔，支持整数和科学计数法。MRT 还可编辑 s_e、s_ε、s_q；剪切模态由黏度决定。预览显示实际腔长、tau、黏度、Ma 和粗略内存/显存估算。实际启动前执行配置及源码验证；预计资源需求超过当时可用资源的 80% 时拒绝分配并记录原因。NEE 的腔长为 N−1，HBB 为 N，坐标及黏度同步转换。详见 [MODEL_SWITCHING.md](MODEL_SWITCHING.md)。

保存模板后，重新打开工作台仍可选用。模板保存单组参数；Re 扫描是独立开关，加载模板时会关闭此前的扫描状态，避免误用旧扫描列表。

启用参数扫描后，可选择 Re、Nx/Ny/Nz、ν、Ra、Pr、α、ax、U、驱动周期、加速度幅值或障碍尺寸，并输入逗号分隔列表；可增加第二轴生成笛卡尔积，每批最多 100 组。所有组先整体校验，校验失败不会提交其中一部分。每一组单独存储参数、状态和结果。

同一工作空间内串行执行 CPU/GPU 任务，避免多个作业同时争用资源。队列中的任务可以前移、后移、取消；当前计算可以暂停、继续、取消。控制采用求解器完整时间步之间的协作检查，不改变碰撞、边界或收敛算法，也不向原 CPU 搜索进程发送信号。

“暂停调度”仅停止后续任务启动，不暂停已经开始的计算；暂停当前计算使用暂停按钮。取消当前任务会尽可能导出已算状态，随后按调度状态处理下一组。

关闭窗口不会取消后台计算或队列。重新打开后可以继续查看和控制。暂停状态保留在进程内存和任务记录中；重启电脑或工作进程异常结束后，记录会标为中断，不会偷偷重跑。新增扩展内核若已有检查点，可从检查点新建续算任务；原方腔内核仍不支持从内存状态恢复。没有活动和排队任务时，后台调度器空闲约 60 秒后退出。

### 流场绘图

在右侧选中任务，打开“流场”页。已有结果也可在“数据档案”中双击打开。除了速度模、水平/竖直速度和密度云图，还支持：

- **流线**：带方向箭头，沿所选步数的速度场绘制；非稳态时不是粒子轨迹。
- **速度云图 + 流线**：速度颜色与流动方向叠加。
- **角涡四联图**：全场速度模、全场流线、左下角和右下角放大，共用同一个保存时刻。
- **区域选择**：单幅图可切换全场及四个角落；角落视野为边长的 10% 至 50%。
- **疏密调节**：0.6 至 3.0，只改变绘图线密度，不改变仿真网格、Re 或求解器。
- **独立窗口**：右上角窗口图标打开当前场的静态快照，标题保留 Re、步数及收敛状态。工具栏可缩放、平移及保存整张图，四联图不会只保存可见滚动区域。

运行中仍读取采样预览，结束后读取原始最终结果；“最终输出”不等于“已收敛”。实时流场图重绘间隔至少约 3 秒，不可见时不计算流线。查看流场时折叠上方数值指标、收紧任务列表，为图表留出空间，切回诊断页恢复；四联图可以纵向滚动或用独立窗口完整查看。

流线使用 Matplotlib 的 `streamplot`。其等间距要求通过按实际 x/y 坐标线性插值满足，支持预览末端不等间距的抽样节点；先截取所选区域再插值，每方向最多 257 点，角落图不会先被全场降采样。插值只服务显示，原始数据不修改。缺失/非有限速度不绘制流线，零速度场明确标注。流线疏密或显示插值都不能作为网格独立性证据；细小角涡仍需加密验证。实现参考 [Matplotlib 官方文档](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.streamplot.html)。

## 数据档案

新任务自动归档。已有 GPU 命令行结果和随包保存的 CPU 低 Re 参照会自动登记；自动登记仅引用原文件，不改写它们。

- 名称、分组和备注可编辑，保存在目录数据库中，与原始计算文件分开。
- 支持按名称、分组、备注或 Re 搜索，并按收敛/未收敛/活动状态筛选。
- 勾选记录后可比较、导出指标 CSV、导出含原始文件和 SHA-256 清单的数据 ZIP。
- 可选择当前筛选列表，也可清除选择；单组参数可复用为新仿真。
- 归档只隐藏记录，不删除数据。勾选“含已归档”后可恢复。
- 导入支持一个结果目录，或包含多组结果子目录的父目录；每组需要有效的 `config.json` 和 `results.npz`。
- 外部导入的文件会复制到本工作空间，并生成来源与哈希记录。不能确认后端的旧外部记录显示“未标注”，不猜测为 CPU 或 GPU。

ZIP 导出包含 `catalog.json` 中的名称、分组和备注，以及各组原始结果。当前导入入口接收目录，不直接解包 ZIP。CPU/GPU 来源、原始参数和停止原因保存在每组原始文件中。

## 对比分析

一次可选 1 至 8 组数据作图；更多记录可导出 CSV。

1. **诊断叠加**：相同坐标中比较残差、质量漂移、Ma、记录耗时或迭代步数。零值保留，缺失和损坏记录保留为空或断点，不补 0。
2. **归一化中心线**：按真实坐标插值至 x/Lx=0.5 和 y/Ly=0.5，比较 ux/U、uy/U，不把偶数网格的某一列冒充几何中心。
3. **参数扫描**：选择 Re、N 或 U 为横坐标；区分收敛点和未收敛点，不将两者混作已验证稳态结果。
4. **流场差值**：恰好两组完整最终流场；可选基准，计算速度差模、相对速度 L2 和最大密度差。物理参数、边界或网格不一致时拒绝直接作节点差值，不暗中插值。基准速度范数为零时，相对误差明确标为未定义。

所有图都保留数据状态。终止步数不同会提示；未收敛场的差异不是稳态误差，也不是 CPU/GPU 同一步等价性证明。绘图工具栏提供缩放、平移、重置和图像保存。

运行中的流场为周期性采样预览，标题标注实际预览步数；完成后切换为原始最终流场。大网格预览会抽样，但最终保存不降采样。当前交互分析不会加载解压后超过 2 GB 的单个 NPZ，以避免界面耗尽内存。

预览文件被 Windows 读取者或同步客户端短暂占用时，写入端最多尝试替换 4 次，总等待不超过 0.1 秒；仍失败则保留旧预览、记录警告并继续计算。后续刷新成功会自动清除当前预览警告，累计跳过次数仍写入记录。读取端先取得有大小上限的内存快照，关闭文件后再解压，预览步数以快照内记录为准。预览不可读不影响已有标量曲线；正式结果、诊断记录或数据库写入失败仍会报错，不会被忽略。详见 `PREVIEW_IO_FIX.md`。

新工作台的“耗时”记录计算、诊断及周期记录所用时间，扣除暂停时间；完整墙钟时间另外保存在结果中。CPU/GPU 性能比较必须匹配网格、参数、预算和报告频率；不能将不同算例的总秒数直接当作后端加速比。

## 文件与边界

默认存储位置：

```text
workspace/
  dashboard.sqlite3       参数模板、队列、名称、分组、备注、结果目录
  runs/<算例 ID>/          由新工作台计算的原始数据
  imports/<导入 ID>/       外部导入的副本和来源校验
  service.log              调度器日志
```

单次输出包括配置、运行请求、逐报告 JSONL、NPZ、中心线与诊断 CSV、最终总结、耗时和分布有限性检查；失败时保留工作日志和错误记录。整个 `workspace/` 应与原 `results/` 一起备份，不要仅复制 SQLite 索引；自动登记的历史结果仍引用它们的原目录。不同机器不要同时操作同一个同步中的工作空间数据库。

“原 CPU 任务”页只读展示原搜索记录和可核验进程状态。原 CPU 看板、暂停任务、搜索队列和 18 个冻结源文件均保持原样；原任务仍由原看板控制。新界面的 CPU 后端会启动独立算例，不是续跑或接管旧任务。

模型支持 D2Q9 顶盖方腔的 BGK/MRT × NEE/HBB 四种组合；均为双精度、质量只报告不补偿、每步残差判断、实际 Ma 保护。NEE 残差使用内部节点，HBB 使用全部流体节点。原始冻结参考保留；热传导、多相、体力及混合壁面不在本次范围内。
