# 开放边界、非定常流与实验分析

2026-09-30 第二轮扩展。继续双击 `open_dashboard_windows.bat`；已经打开的旧窗口需要关闭后重新打开，才能加载新增模块。现在共有 **14 类场景、20 个内置实验**，保留四种流体速度集和 CPU / CuPy / CUDA 三种计算后端。

## 从界面使用

1. 在“内置实验”选择入口出口通道、圆柱尾流、周期驱动力、三维振荡剪切、底热顶冷、混合对流或六圆柱阵列。预设填入相容参数，可继续编辑。
2. 展开“时变驱动、阵列与探针”，设置周期、初相位、入口剖面、出口密度、阵列数量和间距。探针用 `0.5,0.5; 0.75,0.5`；三维每点写三个坐标。最多 8 点，坐标按各方向边长归一化。
3. 可先“几何预览”。三维预览显示 xy 中截面，图像经过采样；实际计算仍使用完整网格。
4. 需要时序流场时，在物性面板设置“场快照间隔”。运行后到“流场”选择保存步数、拖动时间滑块或点击“播放”。回放只读取已保存场，不执行求解器；三维快照可继续切换 xy/xz/yz 截面。选择“当前 / 最终场”恢复实时或最终结果。
5. “探针与频谱”显示探针速度、压力、温度，以及障碍物合力、阻力/升力系数、Nu、进出口质量通量和出口回流比例。时间采样间隔由“报告间隔”决定。
6. “导入配置 / 导出配置”保存单组实验 JSON，包含物理参数、探针、输出设置、名称和分组。导入只填表；需点击开始计算才提交。检查点路径是本机路径，复制配置到另一台机器后应清空或替换该路径。
7. 参数扫描增加 Ny、Nz、驱动周期、加速度幅值和障碍尺寸。勾选第二扫描轴后生成两个列表的笛卡尔积，最多 100 组；两个参数必须不同，所有组合通过校验后才整体入队。关闭主扫描开关即关闭整个矩阵扫描。

## 新场景与约定

| 场景 | 驱动 | 边界与支持范围 |
|---|---|---|
| 入口出口通道 | 左端指定沿 x 的抛物线或均匀速度 | D2Q9；西端 Zou–He 速度，东端固定密度并令 uy=0，上下 HBB |
| 开放通道障碍物尾流 | 同上，加静止圆/方形障碍物或阵列 | D2Q9；开放边界，允许流体质量进出 |
| 周期体力通道 | 手动常加速度加上 x 向余弦加速度 | D2Q9 / D3Q19 / D3Q27；y 两壁静止，其他方向周期 |
| 振荡壁面剪切 | 顶壁作 x 向余弦运动，底壁静止 | D2Q9 / D3Q19 / D3Q27；其他方向周期 |
| Rayleigh–Bénard 对流 | 底部 T=1，顶部 T=0，Boussinesq 浮力 | y 方向无滑移、恒温；x 和三维 z 方向周期 |
| 差温混合对流 | 左热右冷与顶盖沿 x 运动共同驱动 | 封闭 HBB 腔；D2Q9 / D3Q19 / D3Q27 |

新二维场景均支持 BGK/TRT/MRT；三维支持 BGK/TRT。D2Q25 继续限于无固体的全周期场景。温度仍使用独立 D2Q5/D3Q7 分布。

入口的 U 是均匀速度或抛物线峰值；在连续极限下，抛物线截面平均速度为 2U/3。工作台的有效 Re 使用高度 H=Ny：Re=UH/ν。圆柱直径为 D=2r，研究尾流时应另算 Re_D=UD/ν；不能把界面显示的通道 Re 直接当成圆柱 Re。

开放通道 x 边界在最外侧格点，Lx=Nx−1、x_i=i；y 壁面在半格处，Ly=Ny、y_j=j+1/2。速度和密度重构在迁移与壁面反弹后执行，包括四个入口/出口端点。当前压力出口固定横向速度为零，并非无反射远场边界；出口靠近回流区时需要延长下游距离，查看“出口回流格点比例”并做域长敏感性检查。当前开放边界拒绝手动体力和三维模型。

开放系统的 `mass_change` 是域内质量相对初值的真实变化；`boundary_mass_exchange` 是相对于封闭反弹步骤，由入口出口重构引入的累计分布质量。`mass_drift` 改为

\[
\epsilon_m=\frac{|M(t)-M(0)-\Delta M_{\rm boundary}(t)|}{M(0)}.
\]

因此界面统一标为“质量守恒误差”。这项离散记账不能替代物理通量检查；同时记录 `inlet_flux=Σρux`、`outlet_flux=Σρux` 及其差，稳态通道应达到进出通量平衡。瞬态的通量差和域内质量变化本身可以非零。

## 周期驱动及解析验证

所有量采用格子单位 Δx=Δt=1。周期 P 以时间步计，初相位 φ 以 rad 计，ω=2π/P。

周期体力通道使用

\[
a_x(t)=a_{x,\mathrm{manual}}+A\cos(\omega t+\phi).
\]

这里的 A 是“周期加速度幅值”，该场景不自动叠加 Poiseuille 的常驱动力，也不使用壁面启动步数对外力作渐增。初态为静止，故开始时通常包含衰减的启动暂态。Guo 速度用当前时刻的半步加速度修正；迁移后重新求下一时刻的加速度。时变均匀驱动因此对应梯形时间积分。检查点保存绝对步数，续算保持原来的相位。

振荡顶壁速度为 U cos(ωt+φ)，可叠加原有启动渐增；链接反弹在本时间步的中点 t=n+1/2 取壁速。对比解析解时需等待启动暂态衰减。

在平行板 0<y<H 中，从 ∂u/∂t=ν∂²u/∂y²+a_x(t) 推出周期稳态解。令 k=√(iω/ν)：

\[
u_{\rm force}(y,t)=\operatorname{Re}\left[
\frac{A}{i\omega}\left(1-\frac{\cosh[k(y-H/2)]}{\cosh(kH/2)}\right)e^{i(\omega t+\phi)}\right],
\]

\[
u_{\rm wall}(y,t)=\operatorname{Re}\left[U\frac{\sinh(ky)}{\sinh(kH)}e^{i(\omega t+\phi)}\right].
\]

验收使用 H=16、ν=0.1、P=800、φ=0.31，经过 4 个周期后在下一周期取 16 个相位。空间—时间相对 L2 误差分别约 4.168×10⁻⁴、4.784×10⁻⁴，复数第一谐波也达到同一误差水平，覆盖幅值和相位。

## 热对流

三个浮力场景都使用 α=ν/Pr、a_y=Ra να(T−0.5)/H³，H=Ny。Rayleigh–Bénard 初始温度为

\[
T=1-y/H+\varepsilon\cos(2\pi x/L_x)\sin(\pi y/H).
\]

三维预设的初始扰动沿 z 均匀，因此可能保持二维滚胞对称性；选择三维速度集不自动证明形成了三维非定常结构。ε=0、Ra=0 可用于导热对照。底热顶冷的 Nu 以 H 归一化；侧热腔和混合对流的 Nu 以横向传导长度 Nx 归一化。

已检查二维/三维 Ra=0 的线性导热解与 Nu=1。32×16、Ra=5000、Pr=0.71、ν=0.02 的二维滚胞验证运行 18000 步，热壁与冷壁 Nu 约 2.06983、2.06992，最大 Ma 约 0.0526。该结果用于检验浮力与热壁耦合、热平衡和由导热到对流的变化，没有据此声称复现临界 Ra 或高 Ra 湍流。

## 阵列、受力和探针

每个方向最多 8 个障碍物，总数最多 64；中心围绕指定阵列中心对称排列，相邻中心的归一化间距分别按 Lx、Ly、Lz 定义。所有障碍物必须与外边界、相邻障碍物留出流体格点，并在实际网格中占据至少一个格点。圆/球、方形/立方体仍用阶梯掩膜，未实现插值曲壁、移动颗粒或流固耦合运动。

受力取每个完整时间步内，流体—静止固体链接反弹的动量交换；排除外壁，输出所有障碍物合力。报告时刻采样，不为频谱额外计算中间时刻。系数定义为

\[
C_D=\frac{F_x}{\tfrac12\rho_0U^2A_{\rm ref}},\quad
C_L=\frac{F_y}{\tfrac12\rho_0U^2A_{\rm ref}}.
\]

二维 A_ref 为各物体直径/边长之和（单位深度）；三维球取 Σπr²，立方体取 Σ(2r)²。多体使用面积之和，不使用阵列包络面积。这里的 U 是输入参考速度，抛物线入口也是峰值 U。固体动量交换已通过“周期域流体动量变化＋固体受力＝体力冲量”独立预算验证；阶梯几何下 Cd/Cl 的连续极限精度仍需网格对照。

探针取最近网格位置，不插值；记录请求位置和实际位置。若最近格点位于固体，valid=false，速度/压力/温度为空，不挪动探针或填零。压力为相对参考密度的 p′=(ρ−ρ₀)c_s²。探针记录进入 progress.jsonl 和 probes.csv，ZIP 导出包含这些文件。

频谱至少需要 16 个连续有效报告点。可跳过开头一定比例的记录，以排除启动段；去均值后施加 Hann 窗，以窗权和校正单边幅值，DC 和偶数样本的 Nyquist 点不加倍。只允许剔除首尾不规则报告点；内部缺口、非均匀时间间隔、无效探针均明确拒绝 FFT，不作隐含插值。显示 Δf=1/(NΔt)、Nyquist=1/(2Δt)。常量或舍入误差信号不报告周期峰值。图示峰值受记录长度、采样间隔、窗泄漏影响，不能单凭一个 FFT 峰断言涡脱落频率已经收敛。
